# M10 Serializers and Computed Fields

This dependent app verifies the M10 serialization facade.

It covers attached structural and JSON dump methods, field serializers, one
model serializer, a computed field, aliases, selections, typed context, and a
checked serializer error.

Run it with the certified Sifr compiler:

```bash
"$SIFR_BIN" fetch --locked
"$SIFR_BIN" run --locked
```
