# Fields and configuration

This Sifr app demonstrates fields and model configuration. It uses `BaseModel`,
`Field`, `ConfigDict`, aliases, constraints, defaults, and schema annotations.

The app also covers literals, enums, unions, recursive models, and mapped
special values.

Run it with the certified compiler:

```bash
"$SIFR_BIN" fetch --locked
"$SIFR_BIN" run --locked
```

The app exits successfully only when every assertion passes.
