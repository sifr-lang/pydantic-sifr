# Serializers and computed fields

This Sifr app demonstrates model serialization.

It covers structural and JSON dumps, field serializers, a model serializer,
computed fields, aliases, selections, typed context, and checked errors.

Run it with the certified Sifr compiler:

```bash
"$SIFR_BIN" fetch --locked
"$SIFR_BIN" run --locked
```

The app exits successfully only when every assertion passes.
